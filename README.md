## About

I'm a frontend developer based in Tehran, Iran. I build interactive interfaces for dashboards, shopping experiences, developer tools, and applications with multi-step user workflows.

My work focuses on reusable React components, clear state management, responsive layouts, and practical user experience. I also work as a Technical Mentor at Aiolearn.
